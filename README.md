# Personal Portfolio Website

This repository implements a responsive personal portfolio website using only HTML5 and CSS3. It is designed to meet the assignment requirements for semantic structure, accessibility, responsive design, and external styling without frameworks or preprocessors.

## Design Rationale
The homepage uses a strong visual hierarchy with a single `<h1>` heading in the hero section and clearly separated content blocks for About, Projects, and Contact. The site emphasizes readability through high contrast color choices and clear headings. The contact form uses properly associated `<label>` elements for accessibility and supports keyboard focus states.

## Layout Technique Justification
Layout is built with CSS Grid and Flexbox. The About and Projects sections use CSS Grid to create responsive multi-column layouts that adapt at tablet and mobile breakpoints. The hero section, navigation bar, and form layout use Flexbox for flexible spacing and alignment. This combination keeps the site responsive and easy to maintain using native CSS features.

## Responsive Behavior
The stylesheet includes media queries for tablet screens at 768px and mobile screens at 480px. These breakpoints adjust navigation layout, typography, spacing, and section sizing so the site remains usable across desktop, tablet, and phone widths.

## Known Limitations
- No images are currently included, so `alt` text is not present; images can be added later with descriptive `alt` attributes.
- The contact form is a placeholder with `action="#"`; backend integration is not implemented yet.
- No JavaScript interactivity is present, which is acceptable for this assignment and planned for later enhancements.
