Policy Compiler

Jan 2026 - March 2026 | C++17, CMake

A C++ compiler for security policy verification and static analysis.

  • Developed a 6-stage compiler for a custom security policy DSL, implementing lexical analysis, recursive-descent parsing, semantic analysis, policy verification, code generation, and multi-format serialization.
  • Built static analysis modules to detect policy conflicts, privilege escalation paths, and redundant rules, enabling automated verification of RBAC and ABAC access-control policies.
